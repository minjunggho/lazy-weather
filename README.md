# Lazy Weather

Lazy Weather is a weather app that gives human advice instead of just showing numbers.

Instead of saying "18°C", it says things like:
"Today is colder than yesterday, so you might want a light jacket."

## Goal

Build a simple web app that:
- Gets weather data
- Compares today with yesterday
- Uses AI to generate casual weather/outfit advice
- Displays the advice in a clean frontend

## Tech Stack

- Frontend: React
- Backend: FastAPI
- Weather API: Open-Meteo
- AI: OpenAI API
